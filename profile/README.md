**agent-batch is now Elflodge.** See [elflodge.com](https://elflodge.com); the source lives at [elflodge/elflodge](https://github.com/elflodge/elflodge). The `agent-batch` npm package still installs it and runs it under the old name.

For batch document extraction, classification and other repeated agent tasks, install the [Elflodge skill](https://github.com/elflodge/elflodge/tree/main/skills/elflodge-batch-agents):

```sh
npx skills add elflodge/elflodge --skill elflodge-batch-agents
```
